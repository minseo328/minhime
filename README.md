# 피드백 취향 연구소
인적자원관리의 성과관리·구성원 개발을 주제로 한 한국어 5점 리커트 미니 설문.

## 현재 버전: 체험 모드
현재 응답은 브라우저 localStorage에만 저장됩니다. 다른 사람·기기의 응답은 합산되지 않습니다. 화면에도 체험 모드를 표시합니다. 과제의 여러 사람 실시간 공유 조건을 충족하려면 아래 공용 DB 설정이 필요합니다.

## GitHub Pages 게시
Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다. Actions의 **Deploy survey to GitHub Pages** 워크플로를 실행합니다. 게시 URL은 워크플로 deployment 결과에서 확인하세요.

## 공용 결과 연결 (선택)
1. Supabase에서 새 프로젝트를 만듭니다.
2. SQL Editor에서 `supabase.sql` 전체를 실행합니다.
3. `config.js`의 `SUPABASE_URL`, `SUPABASE_KEY`에 프로젝트 URL과 공개 anon/publishable 키를 넣습니다. service_role 비밀키는 절대 넣지 않습니다.
4. 커밋하면 재배포됩니다. 응답은 DB에 저장되고 모든 참여자의 집계가 5초마다 갱신됩니다.
5. 체험 당시 응답은 공용 DB로 옮겨지지 않습니다. 실제 배포 전 사이트 데이터 초기화 또는 새 브라우저로 확인하세요.

익명 UUID로 브라우저 단위 중복 제출을 줄입니다. 로그인 기반 중복 방지나 봇 차단은 아니므로 공개 대규모 운영에는 별도 보강이 필요합니다. 원시 응답 조회 권한을 공개하지 않고 집계 함수만 제공합니다.

## 추가 기능
- 집단별 평균·인원 표시
- 내 응답과 전체 평균 비교
- 점수별 응답 분포
- 집계 CSV 다운로드 (개별 응답 미포함)
- 링크 복사, 모바일 화면, 키보드 입력 지원
- 결과 화면 하단 '이 설문에 대하여': 문항 선택 이유·집단 변수·추가 기능 이유

학습용 자체 제작 문항이며 검증된 척도는 아닙니다. 집단 평균 차이는 유의성이나 인과관계를 뜻하지 않습니다.
